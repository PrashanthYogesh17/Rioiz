Rioiz Worksuite Quickstart

Welcome to the Rioiz developer portal. Rioiz is an interconnected SaaS operating system uniting ERP, CRM, HRMS, Inventory, and Billing into a unified transactional engine.

1. Obtaining Your Workspace API Secret

Every tenant workspace provides a scoped bearer token for automated provisioning and telemetry extraction:

# Authenticate and query active suite health
curl -X GET https://api.rioiz.app/v1/synapse/status \
  -H "Authorization: Bearer rz_live_8f9024ab9e" \
  -H "Content-Type: application/json"

2. Response Payload

{
  "status": "operational",
  "tenant_id": "org_acme_corp",
  "active_suites": ["erp", "crm", "hrms", "inventory", "billing"],
  "sync_latency_ms": 1.18
}
CORE BUS

Synapse Bus Architecture

Unlike legacy software suites connected via asynchronous HTTP polling, Rioiz operates a dedicated relational event bus.

Key Architectural Properties:
Zero Data Inconsistencies: Stock quantities in Inventory and invoice lines in Billing are verified within the same transaction commit.
Sub-Millisecond Sync: Internal state transitions happen directly in the PostgreSQL WAL without network roundtrips.
